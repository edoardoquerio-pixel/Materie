## 2. Metodologie

**Project Management:**
- **PMBOK/PRINCE2**: processi formali, documentazione
- **Agile (Scrum)**: sprint, daily standup, retrospettiva
- **Kanban**: visualizzazione flusso, WIP limit
- **Waterfall vs Agile**: quando usare

**Strumenti:**
- Jira / Trello / Azure Boards
- GitHub Projects con automazioni
- Miro / MURAL per workshop
- draw.io / Lucidchart per diagrammi

## 3. Documentazione Progetto

- **Project Charter**: obiettivi, scope, stakeholder
- **Piano di Progetto**: WBS, schedule, budget, rischi
- **Status report**: settimanale (done, in progress, blocked, next)
- **RAID log**: Rischi, Assunzioni, Issue, Dipendenze
- **Lessons Learned**: fine progetto, cosa ha funzionato/no

## 4. Gruppi di Lavoro

- Formazione gruppi (bilanciamento skill)
- Ruoli: PM, tech lead, developer, QA
- Git workflow collaborativo (branch, PR, review)
- Sprint planning + retro
- Presentazione finale
