# WBS — Work Breakdown Structure (Full Cloud Azure)

```
1.  Project Management
    1.1  Project charter e governance
    1.2  Piano di progetto e WBS
    1.3  Report settimanali e steering
    1.4  Gestione budget e procurement
    1.5  Chiusura e report finale

2.  Assessment
    2.1  Assessment infrastrutturale Thema
    2.2  Assessment infrastrutturale Pro Studio
    2.3  Gap analysis ISO 27001
    2.4  Inventario servizi e dipendenze

3.  Rete e VPN
    3.1  Upgrade FortiGate FG-60F → FG-100F HA
    3.2  Cablaggio strutturato e switch L3
    3.3  Configurazione VLAN e routing
    3.4  Configurazione VPN Sede→Azure
    3.5  Setup 2° ISP ridondante
    3.6  Configurazione VPN client (WireGuard)
    3.7  Test connettività e latenza

4.  Sicurezza (ISO 27001)
    4.1  Configurazione Entra ID + MFA + CA
    4.2  Setup Defender for Office 365
    4.3  Azure Policy e governance
    4.4  Audit iniziale di sicurezza

5.  Cluster HPC
    5.1  Rinnovo licenze cluster on-prem
    5.2  Configurazione Azure CycleCloud
    5.3  Setup Azure Managed Lustre
    5.4  Test job HPC ibrido

6.  Pondus App
    6.1  Analisi compatibilità codice
    6.2  Provisioning Azure App Service + SQL
    6.3  Migrazione database
    6.4  Deploy applicazione su staging
    6.5  Test e validazione
    6.6  Swap to production

7.  Cloud Migration (M1-M11)
    7.1  Foundation (tenant M365, Entra ID, VNet)
    7.2  Posta: Zimbra + GWS → Exchange Online
    7.3  File: NextCloud + Drive → SharePoint/OneDrive
    7.4  Dynamics 365: Sales + BC setup
    7.5  Migrazione dati CRM/ERP/timesheet
    7.6  Azure DevOps: repos + pipelines
    7.7  Media Wiki: VM Azure B2s
    7.8  Test di accettazione
    7.9  Dismissione piattaforme legacy

8.  Backup e DR
    8.1  Configurazione Azure Backup
    8.2  Configurazione Azure Site Recovery
    8.3  Test restore e failover

9.  Offerta
    9.1  Raccolta costi da tutte le aree
    9.2  Redazione offerta tecnico-economica
    9.3  Review e presentazione al cliente

10. Formazione e passaggio di consegne
    10.1  Formazione utenti per area
    10.2  Documentazione utente
    10.3  Affiancamento post-migrazione (2 settimane)
    10.4  Consegna documentazione tecnica
```
