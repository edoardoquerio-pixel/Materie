# Project Charter — Full Cloud Azure

## Dati del progetto

| Campo | Valore |
|---|---|
| Nome progetto | Integrazione IT TP Group — Variante Full Cloud Azure |
| Cliente | TP Group (Thema Consulting srl + Pro Studio srl) |
| Data inizio | 01/09/2026 |
| Durata prevista | 10 settimane (migrazione) + 2 settimane (affiancamento) |
| Budget | € 520.000 + IVA |
| PM | Da nominare |
| Sponsor | Direzione TP Group |

## Obiettivi

1. Migrare tutti i 50 utenti TP Group su M365 Business Premium (posta, file, Teams)
2. Centralizzare identità su Entra ID P1 con MFA e Conditional Access
3. Migrare CRM, ERP e timesheet su Dynamics 365
4. Centralizzare sviluppo su Azure DevOps
5. Migrare Pondus su Azure App Service + Azure SQL
6. Adeguare infrastruttura rete e sicurezza conforme ISO 27001
7. Mantenere HPC on-prem con burst su Azure CycleCloud
