Layer Architetturali 02 / 07

🔐 Layer 1 — Identita & Accesso

  • Entra ID P1 (identity provider unico)
  • Entra Connect Sync (da AD Samba4)
  • MFA obbligatoria su tutte le app critiche
  • Conditional Access (location, device, risk)
  • 50 utenti sincronizzati

💼 Layer 2 — Produttivita M365

  • Exchange Online — posta, calendario (50 GB/utente)
  • SharePoint Online — siti dipartimentali
  • OneDrive — storage personale (1 TB/utente)
  • MS Teams — chat, videoconferenza
  • Defender for O365 — phishing, malware

📊 Layer 3 — Line of Business

  • D365 Sales Professional — CRM (20 utenti)
  • D365 Business Central — ERP (10 utenti)
  • Migrazione: Sugar CRM → Sales
  • Migrazione: Profis + Kimai → BC
  • Migrazione: Odoo → Dynamics

⚡ Layer 4 — App Clienti (PaaS)

  • Azure App Service P1v3 — Pondus (Linux)
  • Azure SQL DB S2 — database Pondus
  • VNet Integration per accesso privato
  • Auto-scaling e health monitoring

🔧 Layer 5 — DevOps

  • Azure DevOps Repos — Git centralizzato
  • Azure DevOps Pipelines — CI/CD
  • Azure Artifacts — NuGet/npm privati
  • Migrazione: GiTea + BitBucket → Repos

📄 Layer 6 — Documentazione (IaaS)

  • VM B2s West Europe — Media Wiki
  • 2 vCPU, 4 GB RAM, 30 GB managed disk
  • Unificazione istanze on-prem + GCP
  • Backup: Azure Backup + snapshot

🖥 Layer 7 — HPC Hybrid

  • On-prem: 8 nodi + InfiniBand (job MPI)
  • CycleCloud head node (VM D2s_v3)
  • Burst: HB176-96rs v4 SPOT (fino a 8 nodi)
  • Azure Managed Lustre — 4 TB shared
  • Forwarder PBS → Slurm

🔁 Layer 8 — Backup & DR

  • Azure Backup — VM, DB, file
  • Azure Site Recovery — DR replica
  • Cold storage 30 giorni (legacy)
  • Snapshot giornalieri managed disk
