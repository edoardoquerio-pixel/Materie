# Inglese Tecnico — Note Complete

## 1. Grammatica Tecnica

- **If-clauses**: Type 0 (general truth), 1 (real future), 2 (unreal present), 3 (unreal past)
- **Passive voice**: `be + past participle` — usato in manuali, report, descrizioni tecniche
- **Relative clauses**: defining (`which/that`) vs non-defining (`, which...`)
- **Comparatives/Superlatives**: `more/less + adj`, `the most/least`
- **Modal verbs**: `must` (obbligo), `should` (raccomandazione), `can/could` (capacità), `may/might` (possibilità)
- **Conditional sentences**: misti, con `unless`, `provided that`, `as long as`

## 2. Lessico Cloud & IT

- **Cloud concepts**: scalability, elasticity, availability, fault tolerance, disaster recovery, latency, throughput
- **Deployment models**: public, private, hybrid, multi-cloud
- **Service models**: IaaS, PaaS, SaaS, FaaS, CaaS
- **Security**: authentication, authorization, encryption, firewall, DDoS, VPN, zero-trust
- **Networking**: subnet, VPC, load balancer, CDN, DNS, TCP/IP, HTTP/HTTPS, TLS/SSL
- **Databases**: relational, NoSQL, ACID, BASE, sharding, replication, indexing

## 3. Business English

- **Cover letter**: struttura (intro → esperienza → motivazione → chiusura)
- **Job profiles**: Cloud Architect, DevOps Engineer, SysAdmin, SRE, Cloud Developer
- **Meeting/Conference call**: scheduling, agenda, action items, follow-up
- **Presentations**: introduzione, body, Q&A, conclusion
- **Reporting**: status report, incident report, project update
- **Crowdfunding**: ITS ICT crowdfunding project (moduli specifici)

## 4. Esercizi Tipici

- Trasformazione attivo/passivo
- Scrittura if-clauses su scenari cloud
- Comprensione testo tecnico (articoli, manuali, documentazione AWS/Azure)
- Produzione testi: cover letter, email professionale, report
- Traduzione IT-EN di termini tecnici
- Reading comprehension con domande
