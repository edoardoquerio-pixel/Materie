# Orientamento e Soft Skills — Note Complete

## 1. Soft Skills per il Cloud Specialist

- **Comunicazione**: chiara, sintetica, adattata al destinatario (tecnico vs business)
- **Teamwork**: collaborazione remota, code review, pair programming
- **Problem solving**: analisi, decomposizione, approccio sistematico
- **Adattabilità**: tecnologie che cambiano, ambienti nuovi, linguaggi diversi
- **Gestione tempo**: priorità (Eisenhower matrix), time blocking, Pomodoro
- **Resilienza**: errori come opportunità di apprendimento, debugging mindset

## 2. Mercato del Lavoro Cloud

- **Ruoli richiesti**: Cloud Architect, Cloud Engineer, DevOps Engineer, SRE, Platform Engineer
- **Certificazioni**: AWS (SAA, SAP), Azure (AZ-104, AZ-305), GCP (ACE, PCA)
- **Skills richieste**: Kubernetes, Terraform, CI/CD, Python, Linux, networking
- **Trend**: multi-cloud, FinOps, AI/ML on cloud, serverless, edge computing

## 3. Employer Branding

- **CV**: chiaro, risultati misurabili, parole chiave, max 2 pagine
- **LinkedIn**: headshot professionale, headline, summary, esperienze, recommendations
- **GitHub**: progetti puliti, README, commit descrittivi, pinned repos
- **Portfolio**: progetti ITS, project work, esperienze stage
- **Colloquio**: STAR method (Situation, Task, Action, Result), domande tecniche e comportamentali

## 4. Career Paths

- Junior Cloud Specialist → Cloud Engineer → Senior Cloud Engineer → Cloud Architect / Team Lead
- DevOps → SRE → Platform Engineering
- Specializzazioni: Security (Cloud Security Architect), Data (Data Engineer), AI/ML (MLOps)
