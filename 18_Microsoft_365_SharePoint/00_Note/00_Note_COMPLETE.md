# Microsoft 365 e SharePoint — Note Complete

## 1. Microsoft 365

**Modelli di licenza:**
- **Business**: Basic, Standard, Premium (fino 300 utenti)
- **Enterprise**: E3, E5 (illimitate)
- **Education**: A1, A3, A5

**App principali:**
| App | Funzione |
|-----|----------|
| Teams | Chat, meeting, collaborazione |
| SharePoint Online | Portali, intranet, document management |
| OneDrive | Storage personale cloud |
| Exchange Online | Email, calendario |
| Viva | Employee experience, OKR, learning |
| Power Platform | Power Apps, Power Automate, Power BI |
| Planner | Task management |
| Lists | Tracciamento dati semplice |

## 2. SharePoint

**Architettura:**
- **Site collection**: tenant con URL proprio (`https://tenant.sharepoint.com/sites/miosito`)
- **Site**: sito moderno (team/communication)
- **Pages**: web part, layout responsive
- **Lists**: dati strutturati (calendario, contatti, tasks, custom)
- **Libraries**: documenti, metadati, versioning
- **Hub Sites**: aggregazione siti con navigazione condivisa

**Modern vs Classic:**
- Modern: responsive, web part, Fluid layout, Power Apps integration
- Classic: compatibilità, template personalizzati, SharePoint Designer

**Permissions:**
- Site: Owner, Member, Visitor
- Unique permissions: break inheritance su subsite/list/item
- Sharing: external sharing (Anyone, Guest, Existing)

## 3. Word + Excel + PowerPoint (Microsoft 365)

- **Word**: document collaborativo, co-authoring, version history, comments
- **Excel**: Power Query, Power Pivot, real-time collaboration
- **PowerPoint**: Designer, Morph, Presenter Coach

## 4. Power Platform

**Power Apps:**
- Canvas App: UI drag&drop, formula Excel-like
- Model-driven App: basata su Dataverse, business process flow

**Power Automate:**
- Trigger: button, schedule, event (email, Teams, SharePoint)
- Actions: approvazioni, notifiche, API calls
- Template pronti all'uso

**Power BI:**
- Desktop: modellazione, DAX, visual
- Service: dashboard, report sharing, data refresh
- Mobile: accesso da app mobile

## 5. Esercitazioni

- Creare site collection SharePoint
- Configurare document library con metadati e versioning
- Power Automate flow: notifica Teams su nuovo documento
- Power Apps canvas app su dati SharePoint
- Excel Power Query da origine esterna
- Word co-authoring e commenti
