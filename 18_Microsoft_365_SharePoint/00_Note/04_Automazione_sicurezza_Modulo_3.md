Dettagli Critici sulla Retention
La Regola dei 93 Giorni
Il timer di 93 giorni inizia alla prima eliminazione e non si resetta passando dal 1° al 2° livello. È un tempo totale condiviso.
Eliminazione Manuale
Se un utente svuota il proprio cestino (1° livello), i file non spariscono ma si spostano immediatamente nel 2° livello.
Impatto sullo Storage
I file presenti in entrambi i livelli del cestino continuano a occupare spazio nella quota di archiviazione della Site Collection.
Backup e Recovery
Cestino SharePoint: I Livelli
Flusso di Recupero
File Eliminato
L'utente elimina un file o una cartella da una libreria documenti di SharePoint o OneDrive.
1
Cestino Utente
(1° Livello)
Visibile all'utente. Il file rimane qui per tutto il periodo di retention o finché non viene eliminato manualmente.
2
Cestino Raccolta Siti
(2° Livello)
 Se svuotato dal 1° livello, il file passa qui. Solo gli Admin possono vederlo e recuperarlo. 
Eliminazione
Permanente
Al termine dei 93 giorni totali, i dati vengono eliminati definitivamente dai server Microsoft.

Salvataggio Automatico
SharePoint e OneDrive salvano automaticamente ogni modifica. Viene creata una nuova versione ogni volta che si salva o si chiude un file.
Ripristino Versioni
Accedi alla "Cronologia versioni" per visualizzare, ripristinare o eliminare versioni precedenti senza sovrascrivere il lavoro attuale.
Limiti Configurabili
La configurazione predefinita conserva le ultime 500 versioni principali. Gli amministratori possono estendere o limitare questo numero.
Gestione dello Spazio
Attenzione allo storage: ogni versione occupa spazio. 10 versioni di un file da 100MB consumano 1GB della quota totale del tenant.
