# 05_Fondamenti_ICT

## 📋 Panoramica

Fondamenti di Information e Communication Technology. Materia propedeutica che introduce i concetti base dell'informatica e delle telecomunicazioni.

## 📚 Indice degli argomenti (attesi dal syllabus ITS Cloud Specialist)

### 1. Architettura dei Calcolatori
- CPU, memoria, bus, dispositivi I/O
- Ciclo fetch-execute, architettura di von Neumann
- Gerarchia di memoria (cache, RAM, storage)

### 2. Sistemi Operativi
- Gestione processi, memoria, file system, I/O
- Kernel vs user space, system call

### 3. Reti di Calcolatori
- Modello OSI e TCP/IP
- Indirizzamento IP, subnetting, routing
- Protocolli applicativi (HTTP, FTP, DNS, SMTP)

### 4. Basi di Dati
- Modello relazionale, SQL, normalizzazione
- Transazioni ACID

### 5. Ciclo di Sviluppo Software
- Algoritmi e flow chart
- Linguaggi compilati vs interpretati
- Version control, testing, deployment

## ⚡ Punti Chiave

- Materia propedeutica — i concetti vengono ripresi in dettaglio nelle materie successive
- La **gerarchia di memoria** spiega le performance dei sistemi moderni
- Il **modello OSI** è tassonomico, il **TCP/IP** è implementativo
