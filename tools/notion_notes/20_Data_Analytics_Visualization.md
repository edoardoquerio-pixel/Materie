# 20_Data_Analytics_Visualization

## 📋 Panoramica

Data analytics e visualizzazione dati. Copre analisi esplorativa, pulizia dati, regressione (lineare, logistica, logaritmica), alberi di decisione, visualizzazione con Excel (grafici, tabelle pivot, Power Query) e Python (Seaborn), dashboard design, storytelling, espressioni regolari e Google Colab.

## 📚 Indice degli argomenti

### 1. Fondamenti di Analisi Dati
- **Analisi Esplorativa (EDA)**: Statistiche descrittive, distribuzioni, outlier, correlazioni
- **Pulizia dei dati**: Missing values, duplicati, outlier treatment, data normalization
- **Esercizio Data Cleaning**: Pratica su dataset Excel con tecniche di pulizia

### 2. Metodi Statistici e Predittivi
- **Regressione Lineare**: Minimi quadrati, R², interpretazione coefficienti
- **Regressione Logistica**: Classificazione binaria, sigmoide, log-loss
- **Regressione Logaritmica**: Modelli non lineari, trasformazione variabili
- **Alberi di Decisione**: Classificazione, regressione, overfitting, pruning

### 3. Excel per Analisi Dati
- **Grafici**: Istogrammi, scatter plot, line chart, box plot
- **Tabelle Pivot**: Aggregazione, filtri, slicer, drill-down
- **Power Query (v3)**: ETL, merge, append, trasformazioni avanzate
- **Dataset Esercizi**: Immobiliare, prestiti, voti fantacalcio, dataset pulizia

### 4. Visualizzazione con Python
- **Google Colab**: Setup, notebook, Python per analisi dati
- **Seaborn**: heatmap, pairplot, boxplot, countplot, distplot
- **Visualizzazione**: Categorical, distribution, relational plots
- **Espressioni Regolari**: Pattern matching per pulizia testo

### 5. Dashboard Design e Storytelling
- **Dashboard Design**: KPI, layout, UX, colori, aggiornamento dati
- **Storytelling**: Narrazione dati, contesto, insight, azione
- **Visualizzazione per Big Data**: Sampling, aggregazione, grafici alternativi
- **Teoria della Visualizzazione**: Pre-attentive attributes, gestalt, chart types
- **Visualizzazione e Storytelling**: Tecniche per presentazioni efficaci

### 6. Prova Finale
- **Quiz finale**: Test di verifica competenze
- **Prova finale**: Esercitazione completa su analisi e visualizzazione

## ⚡ Punti Chiave

- **80% del tempo** va nella pulizia/preparazione dati, solo 20% nell'analisi
- Le **tabelle pivot** sono lo strumento più potente in Excel per aggregazione rapida
- **Power Query** automatizza le operazioni ETL ripetitive
- **Seaborn** è la libreria Python standard per statistical plotting (basata su matplotlib)
- In **regressione lineare**, R² indica la quota di varianza spiegata dal modello
- **Google Colab** permette di eseguire notebook Python senza setup locale
- Per dashboard: meno è meglio — 3-5 KPI chiari, non 20 metriche
