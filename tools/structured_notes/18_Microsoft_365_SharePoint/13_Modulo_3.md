### Slide 6
Cronologia Versioni
OneDrive salva automaticamente la cronologia delle modifiche. Puoi visualizzare e ripristinare versioni precedenti di qualsiasi file.
Ripristino File
Recupera file sovrascritti per errore, corrotti o infetti da ransomware tornando a uno stato precedente con un semplice clic.
Cestino Primo Livello
I file eliminati dall'utente restano nel cestino per 93 giorni e possono essere recuperati autonomamente.
Cestino Secondo Livello
Se il cestino viene svuotato, l'amministratore può ancora recuperare i dati dal "Second-stage Recycle Bin" per un periodo limitato.
