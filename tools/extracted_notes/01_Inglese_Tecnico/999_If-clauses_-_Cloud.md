Grammar - If-clauses 

0° TYPE -100% 

STRUCTURE: IF + simple present + simple present 

EXAMPLE: If I warm water to 100°, it boils 

ITALIAN TRANSLATION: Se scaldo l’acqua a 100 gradi, bolle 

1° TYPE - 90% 

STRUCTURE: IF + simple present + simple future 

EXAMPLE: if it rains, I will take the umbrella 

ITALIAN TRANSLATION: Se piove, prenderò l’ombrello 

 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
 
2° TYPE - 40-50% 

STRUCTURE: IF + past simple + present conditional 

EXAMPLE: if I were a millionaire, I would not be here 

ITALIAN TRANSLATION: Se fossi milionario, non sarei qui 

3°TYPE - 0% 

STRUCTURE: IF + past perfect + past conditional 

EXAMPLE: If dinos had been here, I would have ridden them 

ITALIAN TRANSLATION: Se ci fossero stati i dinosauri, li avrei cavalcati
